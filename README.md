## Testar e implantar

Use a integração contínua embutida do GitLab.

- Comece com GitLab CI/CD
- Analise seu código em busca de vulnerabilidades conhecidas com Static Application Security Testing (SAST)
- Implante em Kubernetes, Amazon EC2 ou Amazon ECS usando Auto Deploy
- Use implantações baseadas em pull para melhor gerenciamento do Kubernetes
- Configure ambientes protegidos

### Sugestões para um bom README

Cada projeto é diferente, então considere quais destas seções se aplicam ao seu. As seções usadas no modelo são sugestões para a maioria dos projetos open source. Tenha em mente também que, embora um README possa ser longo e detalhado demais, é melhor que seja longo do que curto demais. Se achar que o seu README está muito longo, considere usar outra forma de documentação em vez de cortar informações.

## Instalação

Dentro de um ecossistema específico, pode haver uma forma comum de instalar as coisas, como usar Yarn, NuGet ou Homebrew. No entanto, considere a possibilidade de quem estiver lendo o seu README ser iniciante e gostar de mais orientação. Listar passos específicos ajuda a remover ambiguidades e faz com que as pessoas comecem a usar o seu projeto o mais rápido possível. Se ele só funciona em um contexto específico, como uma versão de linguagem de programação ou sistema operacional específico, ou tem dependências que precisam ser instaladas manualmente, adicione também uma subseção de Requisitos.

## Contribuindo

Diga se você está aberto a contribuições e quais são seus requisitos para aceitá-las.

Para quem quer fazer alterações no seu projeto, é útil ter alguma documentação sobre como começar. Talvez exista um script que a pessoa deva rodar ou algumas variáveis de ambiente que precise configurar. Deixe esses passos explícitos. Essas instruções também podem ser úteis para o seu eu do futuro.

Você também pode documentar comandos para lintar o código ou rodar testes. Esses passos ajudam a garantir a qualidade do código e reduzem a chance de que as alterações quebrem algo sem querer. Ter instruções para rodar testes é especialmente útil quando isso exige alguma configuração externa, como iniciar um servidor Selenium para testes em navegador.
